# task_management_task

The Task Management App is a command-line app that allow users to manage their tasks. Users can add, view, update, search and delete tasks stored in SQLite database.

Features 
    Add Task: Add a new task with description, deadline and status.
    View all Task: Display all tasks stored in db by status "pending" first.
    View Task by Status: Filtered tasks based on their status.
    Update Task: To modify exsiting data.
    Search Task by Description: Search for tasks containing a specific keyword.
